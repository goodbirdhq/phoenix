## Features received

- Background service on macOS via launchd, refactored behind a platform-neutral
  `BootServiceManager` (systemd and launchd flows as data).
- `triage` CLI command: hands a misbehaving install to the user's own coding agent (claude or
  codex) with a playbook and machine-context file, plus the matching `via-triage` issue template.
- Letter shortcuts in the right-panel surface dropdown, rendered from one data-driven action list.
- Browser tab mute with an audio indicator on preview tabs.
- Project location subtitles in the new-thread picker.

## Fixes and improvements received

- Desktop: window closes before quit cleanup, unthrottled cold-start paint with re-throttle for
  hidden previews, no quit-shortcut spillover, custom dock icons no longer overwritten on launch
  (packaged builds keep the bundle icon), and no automatic passkey prompts at sign-in (Clerk
  OAuth/passkey dependency upgrades).
- Server: providers Grok, Cursor, and OpenCode are no longer probed unless enabled (new
  per-driver enabled defaults in contracts), PR lookups are bounded away from default-upstream
  inheritance, idle background tasks are not revived by status-free progress events, and GitHub PR
  CLI error transformation was simplified with `Effect.mapError`.
- Threads: a merged PR settles its thread only once, gated on PR update time versus user activity,
  with aligned web/mobile presentation and labeled merge actions.
- Web: sidebar statuses align with project names, the command palette animates when closing
  (one-shot, not continuous), improved disconnected composer placeholder, and local environment
  preview ports open on localhost.
- Mobile: structured input option descriptions are shown.
- Marketing: Apple Silicon Macs are never served the Intel build (Safari included); upstream
  deleted the client-side `macArch` sniffing in favor of a single arm64 asset.

## Follow-up risks

- The marketing site's download and store links predate this sync and still point at upstream
  (`releases.ts`, `site.ts`, hardcoded hrefs in `index.astro`/`download.astro`). Nothing builds or
  deploys `apps/marketing` today, but those must be repointed before the site ships. The merged
  mac download logic now expects an `-arm64.dmg` asset name.
- Fresh installs no longer offer Grok, Cursor, or OpenCode to `list_session_providers` /
  `spawn_session` until the user enables them — intended upstream semantics, worth remembering
  when reading spawn-failure reports.
- Pre-existing runtime artifacts still carry upstream names outside this merge's scope:
  `t3code/pr-<n>/…` checkout branches, `t3code-pr-body-*.md` temp files, and
  `refs/t3code/pre-refresh`. Rebranding them is a separate decision.
- `release.yml` still runs on a cron schedule without a `github.repository` guard and defaults web
  routing to `app.t3.codes` (pre-existing; unchanged by this merge).
