3 CI, 3 build, and one security merge.

- Security: Windows network paths in markdown images, file links, metadata reads and pnpm
  manifests no longer make the server open an SMB session that leaks the user's NetNTLMv2 hash
  (`a12d6ed942`).

  the `typescript` catalog entry, Blacksmith macOS runners, Vercel URL parsing that survives

  thread after history navigation (#23519), right-to-left titles (#22777), ⌘Z undo from the composer
  (#22607), quieter screen-reader status on the open thread (#23752).
- Delegates: Stop stops subagents again (#23886), delegates finish when leftover work settles
  (#22709), Stop on a stuck delegate clears it (#22653), Codex parents resume after native children
  (#23840).
- Usage: ChatGPT Business limits offer a copyable admin request (#23361), OpenCode out-of-funds is
  no longer a usage limit (#22596), Claude usage through proxies (#12069), usage skips disabled
  connections (#22936).
- Telemetry export shows where the endpoint came from (#23713); run durations exported over OTLP
  (#22094).
- Mobile: drafts swipe to discard and every row move animates (#23205), unified draft and thread
  navigation (#23467).
- First dev start seeds a worktree from the live install (#22744), and background worktree setup
  writes setup markers.

## Clean-merge decisions

Phoenix's original delta survives byte for byte in 83 of the 85 files both sides changed that Git
merged without a conflict. The other two are `scripts/dev-runner.ts`, fixed below, and
`.github/workflows/cursor-hygiene-webhook.yml`, which both sides deleted. Other clean-merge fixes:

- `scripts/dev-runner.ts` seeded new worktrees from `~/.t3/userdata`; it now reads
  `~/.phoenix/userdata/statev2.sqlite` (read-only, through `migrate-dev-db`).
- `scripts/setup-worktree.ts` wrote its setup markers to `<worktree>/.t3`; they now go to
  `.phoenix`, which matches AGENTS.md.
- The root `vite.config.ts` excluded `**/.t3/**` from tests; it now excludes `**/.phoenix/**`.
- `apps/server/src/cli/thread.ts`: user-visible errors name Phoenix and the `phoenix` CLI. The
  session label `t3 thread cli` stays, like `t3 connect cli` and `t3 project cli`.
- Upstream text that reaches users now names Phoenix: managed ChatGPT reconnect
  (`managedChatGptToken.ts`), full-access approvals (`threadRequests.ts`), and the ChatGPT Business
  admin request (`usageLimits.ts`). AGENTS.md's new PR-babysitting bullet too.
- `apps/server/src/cloud/selfUpdate.test.ts`: upstream's new prune-on-start tests wrote a `t3`
  executable. They now write Phoenix's `phoenix`, the registered runtime path.
- `.github/scripts/vercel-deployment-output.test.cjs` (new upstream) now checks Phoenix's
  "Deploy and alias channel" step and the web preview step, with the router and domain variables
  that step reads.
- `apps/server/src/provider/model-manifest.json`: taken as upstream's, which Phoenix had not
  changed. Its `t3CodeRange` floors are all `>=0.0.42` or higher, and the server version is 0.1.2,
  so every policy still selects. `providerCompatibility.ts` and `ModelManifest.ts` keep only
  Phoenix's wording and manifest URL.
- Telemetry: `AnalyticsService.ts` was not touched upstream. The no-key short circuit and its test
  stand. #23713 and #22094 only touch OTLP export.
- Palette: upstream's blockquote fix (#24036) inherits the text colour instead of naming a token,
  and the tool-icon fix (#23896) changes classes. Phoenix's token values are unchanged. No palette
  inputs changed, so the mobile themes were not regenerated.
- Settle cascade: upstream's Stop and delegate-lifecycle changes (#23886, #22709, #22653, #23840)
  do not touch the `delegated-tasks.organize` effect. `SettleCascade`, `ThreadStop` and
  `DelegatedCompletionDelivery` tests pass together.
- Package versions moved from 0.1.0 to 0.1.2 and the mobile version from 2.0.0 to 2.1.0. Both were
  inherited from upstream on `v2/base`, and every release and EAS build workflow is dispatch-only,
  so nothing triggers.

## Needs maintainer decision

1. **Command palette hides child sessions.** Upstream's ⌘K search now hides every subagent thread
   (#24032), including Phoenix's delegated child sessions, which the sidebar shows. The palette is
   upstream-owned, so upstream's behaviour was taken. Keeping child sessions searchable would need
   a register row and a Phoenix predicate in `CommandPalette.logic.ts`.
2. **Version trains.** Reborn's desktop and npm version (0.1.2) is below the old fork's last
   release (0.1.21), and its mobile version (2.1.0) is on upstream's train, not Phoenix's 1.0.x.
   Update feeds compare versions, so pick Phoenix's numbering before the first Reborn release.
3. **ChatGPT workspace limit does not fail over.**
   `subscription_sharing_workplace_individual_usage_limit_exceeded` stays `provider_error`, as
   upstream wants, so a failover group does not switch accounts on it. Switching would help when
   the next account is in another workspace.
4. **OpenCode out-of-funds does not fail over** since #22596. The register row only covers Codex
   and Claude, so this matches it; say if OpenCode groups should switch.
