# Mobile notifications

Remote agent notifications and ongoing activity delivery are currently unavailable.
**Device Notifications**, **Ongoing Agent Activity** on Android, and **Live Activity
Updates** on iOS cannot be enabled for remote delivery in this version.

Pairing over HTTP or Tailscale lets you work with an environment while connected;
it does not enable background push alerts or Live Activity updates. Open Phoenix
and connect to the environment to check your agents' progress.

Notification permissions and existing Android notification channels remain under
system Settings. Granting permission does not enable a delivery service.
