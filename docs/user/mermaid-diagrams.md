# View Mermaid diagrams

Phoenix can show a Mermaid diagram from a `mermaid` code block in a conversation or a Markdown file preview. Choose **View diagram** in the code block to open it. The diagram opens only when you choose it, so a long conversation or file can contain many diagrams without loading them all at once.

Use **Fit**, **Zoom in**, **Zoom out**, and **Reset** to inspect a large diagram. Choose **Show source** to read or copy the text. Close the viewer with its close button, Escape on web and desktop, or Back on Android.

In a Markdown file, switch to the rendered preview to find **View diagram**. The file's source view keeps the original Markdown text.

Phoenix renders the selected diagram on your device, including when you are connected to a remote environment. It does not send the diagram to an external website. If the diagram has invalid Mermaid syntax or cannot be rendered, its source remains available to read and copy.

The viewer is available on web, desktop, and Android. On iOS, Mermaid blocks remain readable as source text.
